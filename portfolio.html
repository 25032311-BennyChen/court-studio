Study Session Tracker

A web application for managing and organising study session records.

PROJECT TYPE
Individual web application development project
TECHNOLOGIES
Node.js, Express.js, EJS, JavaScript, HTML and Bootstrap

The purpose

Keep study session records in one application, with controls to create, read, update and delete them.

02 / APPLICATION DEVELOPMENT / GROUP PROJECT

Lawn & Found

A campus lost-and-found application where authenticated users can submit reports and browse active listings.

PROJECT TYPE
Group web application development project
TECHNOLOGIES
Node.js, Express.js, EJS, JavaScript, MySQL (Azure) and HTML

My contribution to the group project

  • Developed the core report creation and viewing features for Lost/Found reports and active campus listings.
  • Implemented MySQL INSERT, SELECT and UPDATE queries, including JOINs to retrieve reports with their category and location information.
  • Built a Lost Item Found Notification workflow so finders can notify report owners with a message and an optional image.
  • Added backend ownership verification and report status updates so only the report owner can confirm recovery or mark their own lost item as recovered.
  • Created dynamic EJS templates with conditional action buttons based on report type, status and the logged-in user’s permissions.

03 / APPLICATION DEVELOPMENT / GROUP PROJECT

SharePlate

A group food-donation web application, with my work focused on donation data, validation and automated security checks.

PROJECT TYPE
Group web application
TECHNOLOGIES & WORKFLOW
React, Node.js, Express.js, MongoDB Atlas, Mongoose, Jenkins, Trivy, Docker and DevSecOps

My contribution to the group project

  • Designed Mongoose database schemas and REST API endpoints, including GET /api/donations and POST /api/donations, to store, validate and retrieve donation records.
  • Implemented client- and server-side validation for food names, positive whole-number quantities, location text and food expiry dates.
  • Integrated automated security gates into the Jenkins CI/CD pipeline using Trivy to scan repository code, dependencies and Docker images before release.
