COURT STUDIO / PERSONAL PROJECT / IN PROGRESS

A personal portfolio.
A clear direction.

Connecting my full stack studies, interest in design and love of badminton in one place.

PROJECT TYPE
Personal portfolio
TECHNOLOGIES
HTML, CSS & JavaScript
CURRENT STATUS
In development

The purpose

Introduce myself to potential internship employers and create a place to share my projects, my contribution and the learning behind each piece of work.

The design direction

A calm ivory background, forest green typography and lime accents. The badminton court gives the layout its structure, with movement and practice as recurring ideas.

The build so far

Responsive Home, Portfolio, About and Contact pages, with mobile navigation, project category filters and accessible project dialogs. The site uses plain HTML, CSS and JavaScript and is published with GitHub Pages.

What comes next

Add real coursework, expand the project case studies, and add my personal photo and verified certifications. This is an ongoing personal project, rather than a finished coursework case study.
